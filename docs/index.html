ElementaryOS M-Series

Experimental port of elementary OS 9 (Pantheon, Ubuntu-based) to Apple Silicon Macs (M1/M2/…), informed by the maintained Apple hardware packages in omacom/omarchy-mac-pkgs.

Status: elementary OS 9 boots to Pantheon on an M1 Pro. This is an installed, transformed system using the experimental Fairydust USB4 kernel. The separate mkosi arm64 factory ISO has not yet been built or hardware-booted, and no ISO is published.

Download

No ISO is published yet. The successful desktop boot does not validate the factory image or the stock Ubuntu arm64 kernel. The M-series CI workflow checks wiring and scripts; a factory image still needs a successful build and hardware boot before release.

  • Build instructions: upstream elementary/os.
  • Changes to the M-series image and transform paths trigger the Validate M-series wiring workflow on arm64 runners.

Cutover quickstart (omarchy-mac side)

On a booted omarchy-mac, dry run first — changes nothing, uploads its log:

git clone --depth 1 https://github.com/techmore/ElementaryOS_MSeries && sudo ./ElementaryOS_MSeries/transform/elementary-grow.sh --upload

Paste the printed gist URL back for review. Post-boot verification checklist: POST-BOOT-CHECKS.md.

How this differs from Asahi / Omarchy installers

This project includes an image factory and an experimental transform path. The transform script adds an elementary boot entry beside an existing omarchy-mac install; review its dry-run output before applying it. The factory ISO is a separate path and is not yet hardware-verified.

Support & parity

Support and evidence matrix records what has actually been observed on the M1 Pro, separately from the unverified factory ISO. See the specific bug-fix list for resolved documentation/build gaps and the next hardware fixes.
