ElementaryOS M-Series

Experimental port of elementary OS 9 (Pantheon, Ubuntu-based) to Apple Silicon Macs (M1/M2/…), informed by the maintained Apple hardware packages in omacom/omarchy-mac-pkgs.

Cutover quickstart (omarchy-mac side)

On a booted omarchy-mac, dry run first — changes nothing, uploads its log:

git clone --depth 1 https://github.com/techmore/ElementaryOS_MSeries && sudo ./ElementaryOS_MSeries/transform/elementary-grow.sh --upload

Paste the printed gist URL back for review. Post-boot verification checklist: POST-BOOT-CHECKS.md.

How this differs from Asahi / Omarchy installers

This project includes an image factory and an experimental transform path. The transform script adds an elementary boot entry beside an existing omarchy-mac install; review its dry-run output before applying it. The factory ISO is a separate path and is not yet hardware-verified.
