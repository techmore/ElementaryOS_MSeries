ElementaryOS M-Series

Experimental port of elementary OS (Pantheon, Ubuntu-based) to Apple Silicon Macs (M1/M2/…), informed by the Apple Silicon hardware knowledge in omacom/omarchy-mac (quattro).

Status: scaffolding — no tested ISO yet. The build wiring exists and passes CI config checks, but no image has been built or booted on Apple hardware. Everything below is the plan being tracked in the open.

Download

No ISO is published yet. When the first arm64 build succeeds, ISOs will be attached to GitHub Releases. Until then:

  • Builders: just do-daily on an arm64 Ubuntu machine (see upstream README), or run Daily OS 9 via Run workflow in Actions.
  • Every change to the build wiring is config-checked on real arm64 runners (Validate M-series wiring).

Cutover quickstart (omarchy-mac side)

On a booted omarchy-mac, dry run first — changes nothing, uploads its log:

git clone --depth 1 https://github.com/techmore/ElementaryOS_MSeries && sudo ./ElementaryOS_MSeries/transform/elementary-grow.sh --upload

Paste the printed gist URL back for review. Post-boot verification checklist: POST-BOOT-CHECKS.md.

How this differs from Asahi / Omarchy installers

This project is an image factory, not an installer command. Asahi ships an installer app you run from macOS; Omarchy ships a script you run inside an already-booted Linux. Here, CI builds a bootable live ISO (hours, in the cloud); you flash it to USB and boot it. There is no one-line command that transforms your running Mac — and nothing here can touch your Mac until you deliberately boot media it produced.

A second, design-stage track exists for machines already booting omarchy-mac: a single grow-from-omarchy command (transform/elementary-grow.sh) that adds an elementary boot entry alongside the old system. Dry-run review on the real machine comes before any --apply.
