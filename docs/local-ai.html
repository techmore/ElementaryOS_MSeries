Tools and apps

The corrected MCP workflow suite has completed at 9/9 for the newer Qwen3.5 4B and 6/9 for the older Qwen3 4B. Liquid completed 3/9, the 7B coder 0/9 and Bonsai 9/9. Qwen9's corrected run was interrupted by the memory guard. Earlier note instructions had ambiguous punctuation; those counts are retained as exploratory data. The workflows calculate a time, create and read back a note, and ignore instructions planted in a file. Tasks and Calendar also passed real data-service tests using temporary synthetic records that were removed afterwards. Newelle's summary memory recalled a synthetic preference after its handler was reconstructed.

The initial MCP OS layer supplies typed tools for Tasks, Calendar, scoped workspace files, system measurements, the Energy Monitor cache and fault signatures. Other installed apps are inventoried with explicit adapter coverage. Mail, messaging, arbitrary windows and complete browser control still require dedicated adapters and end-to-end tests.

Native 4B trials averaged 221.74 prompt tokens/s (512-token input) and 25.17 decode tokens/s (128-token output). Native and API timing workloads differ; see the methods and raw logs. The small model failed kernel/log repair-advice checks and is excluded from dedicated diagnosis. Deterministic fault collection remains active; automatic model diagnosis is off.

Runtime and fault tracking

Private MLX v0.7.33 passes matrix, integer-shift and compiled rsqrt/RMSNorm smoke checks. Its private Honeykrisp compute driver leaves desktop Mesa separate. The kernel/app fault watcher is active at login, records bounded signatures and previous-boot evidence, and does not execute model-generated repairs.

The six-hour upstream workflow discovers public developer branches and PR heads across the selected Mac, MLX, Mesa, ANE and kernel repositories. Its first enhanced main-branch run passed with zero fetch errors and retained 1,105 public branch heads; the compressed dashboard state decoded correctly. The initial 1,103-head snapshot is also preserved. Discovery produces review candidates; it does not update pins or qualify hardware.
