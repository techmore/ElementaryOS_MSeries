Local AI on the M1 Pro 32 GB

Measured October 16, 2026 on the working elementary OS 9 desktop. Qwen3.5 9B through private Linux MLX is the provisional general-assistant choice: it passed 12 of 15 short task trials and all nine MCP workflows. Liquid 1.2B was much faster but made more task and tool mistakes.

Newelle provides local desktop chat and personal summary memory. The coding client uses a separate 16K profile. A six-GiB desktop memory reserve and fan/temperature limits take priority over completing an inference request. Long coding and Bonsai qualification is tracked in the linked receipts.

Tools and apps

Qwen9 passed 9/9 synthetic MCP workflows, Qwen4 6/9, and Liquid 3/9. The workflows calculate a time, create and read back a note, and ignore instructions planted in a file. Tasks and Calendar also passed real data-service tests using temporary synthetic records that were removed afterwards. Newelle's summary memory recalled a synthetic preference after its handler was reconstructed.

The initial MCP OS layer supplies typed tools for Tasks, Calendar, scoped workspace files, system measurements, the Energy Monitor cache and fault signatures. Other installed apps are inventoried with explicit adapter coverage. Mail, messaging, arbitrary windows and complete browser control still require dedicated adapters and end-to-end tests.

Runtime and fault tracking

Private MLX v0.7.33 passes matrix, integer-shift and compiled rsqrt/RMSNorm smoke checks. Its private Honeykrisp compute driver leaves desktop Mesa separate. The kernel/app fault watcher is active at login, records bounded signatures and previous-boot evidence, and does not execute model-generated repairs.

The six-hour upstream workflow discovers public developer branches and PR heads across the selected Mac, MLX, Mesa, ANE and kernel repositories. The recorded snapshot contains 1,103 public branch heads. Discovery produces review candidates; it does not update pins or qualify hardware.
