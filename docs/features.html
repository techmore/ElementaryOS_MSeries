M1 Pro features and Omarchy parity

What the installed elementary OS 9 desktop does on a 14-inch MacBook Pro (M1 Pro), checked against the maintained Omarchy Apple Silicon packages (omacom/omarchy-mac-pkgs, audited at 222f7a8). This describes the installed system, not the unbuilt factory image. Updated 2026-10-14.

New repository candidates — October 17

Sleep-energy logging and a power-report launcher are implemented in the repository, with Touch ID readiness and setup fixes. Bluetooth resume recovery and built-in F-key remaps are separate opt-ins. These additions have offline regression coverage; target-machine qualification and factory-image boot remain pending. See the audit, installation options and measurement limits. This does not change the installed-system results below or establish a battery-life improvement.
