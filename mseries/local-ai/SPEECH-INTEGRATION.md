# Speech, translation and grammar integration decision — October 18, 2026

The broader [agent-first Pantheon MCP and WebRTC feature proposal](PANTHEON-MCP-DESIGN.md) includes alerts, workflow agents and desktop capabilities. This note records the narrower capture/review decision.

The existing F5 implementation already supplies the native capture path. Extend that implementation rather than add a second microphone daemon or a second resident language model. See [dictation implementation and measured limits](../dictation/README.md) and [speech research](../dictation/STT-RESEARCH.md).

Current source and service inspection found the streaming `mseries-stream-dictate` unit active. It uses transcribe.cpp 0.4.0 with pinned Parakeet Unified EN 0.6B Q4_K_M, opens the built-in AOP array only while F5 is held, filters/resamples the three channels, and now sends committed Unicode text through the activated, focus-bound IBus bridge on CPU; ydotool remains the explicit compatibility path. Existing offline fixtures and timings belong to that work; this app-integration qualification did not record the microphone, inject global keystrokes, change audio routing or repeat ASR benchmarks. Main commit b20c808 subsequently fixed that failure: the AOP capture path must read FLOAT_LE explicitly. The installed script matches the corrected source. Its published loopback/self-tests report successful recognition; they do not prove a person-to-app session. Universal app insertion, non-US layouts, noisy human speech accuracy and translation remain unqualified.

The owner's updated priority is universal F5 dictation first, a high-capability troubleshooting/optimization agent second, then a low-overhead everyday machine assistant. Gmail is the preferred mail integration; local unsent Mail drafts remain an optional adapter and separate evidence, not Gmail support. The broader agent tiers share typed capabilities and the quiet-gated runtime rather than starting extra resident models.

The useful control-panel extension is a visible recording state, language/output preferences and an **opt-in review mode**. Keep raw transcription visible. In review mode, collect a finalized utterance before asking the existing quiet-gated 4B endpoint for grammar correction or translation; display original and proposed text together, then let the person copy/insert the result. Committed streaming text must not be silently replaced in another app. A missed quiet admission should leave the raw text available, without starting another GPU worker. Do not route a review transcript through shell tools or treat dictated text as agent instructions.

That review step can later create a workspace note or unsent Mail draft through the same typed adapters. Creating a task/event must still be an explicit request with a retry ID. Translation requires a measured multilingual model and references; the currently installed English streaming model does not establish translation support. Benchmark raw and corrected text on the same consented clips, preserve correction errors/deleted facts, record end-to-final latency and fan/RAM samples, and test insertion in isolated app fields before claiming universal app support.

Universal insertion now has an activated IBus bridge requiring AT-SPI field metadata and STREAM_OUTPUT=ibus. Seventeen contracts pass. Real GTK3 X11/GTK4 Wayland, Qt6 single/multiline, accessibility-enabled Brave and a synthetic Electron 44.4.5 form pass Unicode, changed-field and password checks. Begin acquires the engine for one utterance, and queued Finish/Escape restores the previous method without altering native layout sources or restarting IBus. Deliberate owner layout changes are preserved. The permanent-selection approach and browser startup-metadata failure remain recorded. Existing Chromium processes without accessibility metadata fail closed and require their next accessibility-enabled launch; no running owner window was closed. Actual Codex/OpenCode sessions and a human F5 round trip remain unverified.

The staged manager preserves private original-file/preference baselines, refuses owner-file conflicts and checks for active capture before changes. Stage-only rollback and a full rollback/reactivation cycle were exercised, including a retained provider-stop restore-order failure and subsequent fix. The current session-scoped services report ready with CPU/IBus while the ordinary keyboard source stays selected at idle. Changed-source CPU speech-to-field on the public clip passed at 0% normalized WER, first text 5.09 s, minimum available 9.00 GiB and maximum fan 2523 RPM. Frozen code and original failures are published separately from prior v4 results; these are functional checks, not general speech accuracy or a ranking. The everyday model's memory-reserve stop during mixed workload is retained; enabled state is preserved and restart must pass admission.

Whisper fallback uses an anonymous RAM descriptor, checked against the actual CLI. No microphone, owner window or audio-route manipulation was used for these new tests. Grammar/translation review remains proposed and unimplemented; English-only ASR does not prove multilingual capture or translation.
