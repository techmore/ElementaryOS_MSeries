# M1 Pro Qwen 4B batching test — 2026-10-27

Available memory rose naturally without closing applications or stopping any
services. A guarded 4B smoke was admitted at 12.69 GiB available using the
6.5 GiB model allowance and 6 GiB desktop reserve; with process-local 20k
batching it loaded in 4.16 s, answered `19`, and exited in 7.07 s. The answer
is a smoke test, not a correctness qualification.

Then six fresh processes ran alternating baseline/candidate pairs with the
same 27-token prompt, 32 greedy generated tokens and one warmup per process,
with a visible GTK animation probe. Model is
`mlx-community/Qwen3.5-4B-MLX-4bit` at
`32f3e8ecf65426fc3306969496342d504bfa13f3`, weights SHA-256
`5fb9acd0246866381cf8c5c354c6db1019f6498eec4ccb4f5edcc71ffeacb2db`.
The guarded harness enforces this hash, the 6.5 GiB admission allowance,
6 GiB runtime reserve, 80 C guard and shared lock. No defaults changed.

| Pair | 5,000 baseline request | 20,000 request | Request-time reduction |
| --- | ---: | ---: | ---: |
| 1 | 2.409 s | 2.099 s | 12.86% |
| 2 | 2.459 s | 2.187 s | 11.05% |
| 3 | 2.421 s | 2.097 s | 13.40% |
| Median | — | — | **12.86%** |

MLX-reported median generation rate was 19.46 → 23.29 tokens/s; counters
showed 823 → 249 submissions per measured request (including prefill).
All six 32-token outputs matched; this does not prove logits fidelity or
correctness across models and prompts. Available memory fell no lower than
10.93 GiB in the sampled runs; max temperature was 50.266 C and fan 2515 RPM.

The desktop animation probe saw no callback gap over 33.33 ms in 433 baseline
intervals (max 25.64 ms); the candidate had one in 377 intervals (max
50.49 ms). These are GTK callback timings, not presentation or input latency;
one of the short runs demonstrates sustained desktop responsiveness. The
result argues for more testing before any default change.

The experimental ANE decoder was not run: beyond memory, the compatible
compiled 38-program bundle and manifest are absent, and the converter's
header-unit tests need resolution. See [ANE preflight](2026-10-27-ane-qwen-preflight.md).
