# Attribution

Orchard for Incus is a Linux/Pantheon re-imagining of
[Orchard](https://github.com/andrew-waters/orchard) by Andrew Waters (MIT licensed),
a native macOS manager for Apple containers. Feature design (instance dashboard,
one-click lifecycle, snapshots, shell access) is inspired by Orchard. The code is
a fresh Vala/GTK4/Granite implementation against the Incus REST API; no Orchard
source was copied. The MIT license in `LICENSE` is Orchard's, retained for attribution.
