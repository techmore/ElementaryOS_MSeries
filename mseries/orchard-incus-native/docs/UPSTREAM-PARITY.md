# Orchard upstream parity

Reviewed upstream: `2c78257c8602ffed61f383ee6e737bfc37b142ee`.

Scope: native Vala/GTK/Granite, Incus only. The owner selected an Incus-only runtime; no Podman, Docker or Apple runtime is installed by this work.

This is a feature-by-feature comparison, not a claim of full parity. Implemented means a concrete UI/backend path exists; adapted means a native Incus counterpart exists with the stated behavior differences; partial means meaningful behavior is still missing; incompatible means the upstream contract is outside the installed runtime/platform target. Incus addition identifies scope beyond the upstream comparison. Tests and live verification are stated separately.

Incus addition: 2, adapted: 38, implemented: 54, incompatible: 37.

OCI application-container support was introduced in Incus 6.3; the incompatible OCI classifications here describe this installed 6.0.5 target and this implementation, not all future Incus versions. No host runtime upgrade is performed.

Runtime references: https://discuss.linuxcontainers.org/t/incus-6-3-has-been-released/21019, https://github.com/lxc/incus/blob/v6.0.5/doc/rest-api.yaml

## Verification and limits

Validated on aarch64 elementary OS with Incus 6.0.5: application and Wingpanel module compile; five automated suites pass (Incus protocol/JSON/config round trips, model HTTP/auth and bridge policy, restart/ETag races, indicator states, and construction of native windows against disposable fixtures). Live owned-container checks cover config/device preservation, stop/apply/start with runtime ETag changes, snapshots, copy, pause/resume, restore and streamed export. A temporary host-only bridge allowed a host service and blocked cross-network guest traffic without an IPv6 default route. A newly created native Alpine VM booted and its guest agent executed a command with the configured environment. All temporary instances/networks were cleaned up; existing Rupert and orchard-test workloads were not changed. GTK fixture tests validate construction and initial reads, not a complete manual click-through. Actual keyring credential storage, external model generation, privileged host daemon controls, and every possible image/network configuration have not been live-tested. No production SER8 changes or runtime upgrade are included.

The complete feature-view and service-symbol inventory is retained alongside this ledger. A source file appearing in the inventory does not imply its behavior has been ported. New upstream revisions require a new review.
