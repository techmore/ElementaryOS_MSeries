Useful features: daily local/GitHub activity grouped by repository, source links,
safe recap copy, local calendar-day semantics and graceful source failures.
Native implementation belongs in the existing Rust GTK/Granite T3 window,
reusing its pinned repositories and gh credential boundary. The Quattro shell,
QML, wl-copy, Omarchy plugin installation and another indicator are unnecessary.

This batch implements a native Activity page and distinct read-only model and
bounded collector. It preserves user-authority boundaries: no GitHub writes,
runner activation, handoff edits, automatic commits, daemon, auto-export or Omi
upload. See [ACTIVITY.md](../../../rust/claude-pantheon-rs/docs/ACTIVITY.md) for
the user flow, exact semantics, limits and source status.

Upstream caveats intentionally addressed: first-page-only searches silently
truncate; authored closed issues are not issues closed by the user; local commits
are not proof of push; local committer time differs from search author time;
email regex matching is broader than exact identity; a timed-out local stream can
be marked fresh before exit success; untrusted recap destinations require URL
and Markdown validation. New source states distinguish unavailable, partial,
fresh and last-known records. Day filtering has both lower and upper bounds.

`rust/claude-pantheon-rs/licenses/shiplog-MIT.txt`. No upstream QML assets or
sponsor-only content were imported. New Rust behavior is based on the public
contract and source review; initial tests use our synthetic fixtures.
